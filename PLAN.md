# Plan

The roadmap is tracked in GitHub issue
[#23](https://github.com/hanthor/Notes-Of-Fruit/issues/23) and the issues
linked from it. This file used to hold the original build plan; everything it
listed as missing (new-note FAB, auto-save, format display and toolbar, folder
navigation, image display) has shipped, so it was retired.

## Design decisions

The design decisions from the original plan (Q1–Q9: attribute_runs instead of
Markdown, lifecycle-only auto-save, empty-body new notes, plaintext share,
deferring Share IN, the FAB, the package rename) are kept as a historical
record in [docs/design-decisions.md](docs/design-decisions.md).
